# NIVARA

**NIVARA is an accessibility-intelligence dashboard that maps pedestrian barriers, ranks them by impact, and can detect barriers in street photos with a trained YOLO model.**

Built by **ERROR 404: Winner Not Found**.

## What it does

- Shows a city map and a priority queue for simulated accessibility barriers.
- Scores barriers using severity, footfall, time unresolved, and the selected mobility group's impact.
- Lets users upload a street photo for YOLO object detection.
- Maps detected classes to barrier categories such as encroachment, construction, or parked vehicles.

> The map and priority data are currently demo data, not live reports.

## Setup on Windows

This project uses the virtual environment at `E:\Nivara\venv`. From PowerShell:

```powershell
Set-Location 'C:\Users\subho\Desktop\Code\Nivara'

# Install CPU-only PyTorch first.
& 'E:\Nivara\venv\Scripts\python.exe' -m pip install --index-url 'https://download.pytorch.org/whl/cpu' torch torchvision

# Install the remaining app and training dependencies.
& 'E:\Nivara\venv\Scripts\python.exe' -m pip install -r requirements.txt
```

## Run the dashboard

```powershell
Set-Location 'C:\Users\subho\Desktop\Code\Nivara'
& 'E:\Nivara\venv\Scripts\python.exe' -m streamlit run main.py
```

The dashboard uses `best.pt` beside `main.py` when it exists. Without it, the dashboard still runs, but image detection remains in demo mode.

## Train the YOLO model

Training runs locally on the CPU for 50 epochs with 640-pixel images, batch size 8, and 2 workers.

### Use the local dataset

The current dataset is private. If you have access to it locally, point `YOLO_DATA` at its YAML file:

```powershell
Set-Location 'C:\Users\subho\Desktop\Code\Nivara'
$env:YOLO_DATA = (Resolve-Path '.\dataset\data.yaml').Path
& 'E:\Nivara\venv\Scripts\python.exe' train.py
```

Training runs are saved under `E:\Nivara\training\runs` by default, and the best weights are copied to `best.pt` beside `main.py`.

### Download a dataset from Roboflow instead

If `YOLO_DATA` is not set, `train.py` uses these environment variables to download the dataset:

```powershell
$env:ROBOFLOW_API_KEY = '<your API key>'
$env:ROBOFLOW_WORKSPACE = '<your workspace>'
$env:ROBOFLOW_PROJECT = '<your project>'
$env:ROBOFLOW_VERSION = '1'
& 'E:\Nivara\venv\Scripts\python.exe' train.py
```

Keep the API key in your local environment; never commit it to the repository.
